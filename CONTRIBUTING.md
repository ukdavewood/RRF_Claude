# Contributing

This is an experiment in sharing, not a maintained software product. The guides describe how things were built with an AI coding assistant, and the repository is meant to grow into a shared notebook of what other people tried.

## What is welcome

- Alternative approaches and other implementations (another operating system, headset, CAD program or AI tool).
- Corrections and improvements to the guides.
- Discoveries, workarounds and fixes.
- Prompts that worked better (or worse).
- Demonstration videos and links.
- Reports of problems and things that failed. A failed attempt is useful.

You don't have to contribute code. **Contribute knowledge.**

## How

Use whichever is easiest:

- **Discussions**: ideas, experiences, questions, alternative approaches.
- **Issues**: a problem, a bug in a guide, a compatibility report.
- **Pull requests**: add a Markdown note to `community-knowledge/` (copy `community-knowledge/TEMPLATE.md`), or propose a change to a guide.

A good contribution says what you tried, which AI tool and platform you used, what worked, what didn't, and which version of the guide you started from. A short note is fine.

## What to expect

- **There is no commitment to review, merge, build, maintain or support any contribution.** Pull requests may never be merged.
- Issues, discussions and pull requests, merged or not, are part of the public record. They are written to be read by people **and by AI assistants** that search them before starting a new project. See [AGENTS.md](AGENTS.md).
- Help is community-led and best effort.
- Please say whether you tested something. An unmerged pull request is not a working solution unless its author shows that it worked.

## Please don't include

- API keys, signing keystores, access codes, passwords or other secrets.
- Personal information (real names, emails, private file paths) that you don't want public.
- Third-party code or files you don't have the right to share (for example vendor libraries that must be downloaded from the vendor).

## Licensing

Unless a file says otherwise, contributions are shared under the same terms as the rest of this repository. If you add third-party material, credit it and check its licence.

AI-assisted contributions are welcome. Say which assistant you used and what you checked yourself.
