# Community knowledge

A shared notebook of what people tried with the guides in this repository. Add a Markdown note about your own attempt, however small.

- Copy [TEMPLATE.md](TEMPLATE.md), fill in what you can, and add it here as a pull request (or paste it into a Discussion).
- Name the file after the guide and your variation, for example `quest-viewer-windows-server.md`.
- It does not have to be merged to be useful: pull requests, issues and discussions are part of the record too.
- Say what you tested. Mark untested ideas as untested.
- No secrets, no personal details.

No one is committed to reviewing or maintaining these notes. Treat them as other people's experience, not as verified instructions.
