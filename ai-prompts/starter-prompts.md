# Starter prompts

Paste one of these into your AI coding assistant (Claude Code, Codex, Gemini, ChatGPT or similar). Replace the parts in angle brackets.

## Recreate a guide's project

> Read <link to the guide> and <link to this repository's AGENTS.md>. Check the guide's version block and tell me if my setup differs. Read the sample code it links to, if any. Then search this repository's issues, discussions, pull requests (including unmerged ones) and community-knowledge folder, and tell me what other people have tried, marking each as tested, untested, abandoned or conflicting. Propose a plan for building my own version on <my computer and devices>. Don't write code until I approve the plan.

## Adapt it to my platform or tools

> I want the project in <guide> but on <different platform, device or tool>. Read the guide, the sample code and the community notes. List which parts are tied to the original platform, what I'd need to replace, and the risks. Propose a plan and wait for my approval.

## Compare approaches before choosing

> Research the original guide, the sample code and every community contribution, issue, discussion and pull request for <project>. Identify the different approaches people have tried, what succeeded and failed, and recommend the best starting point for a new implementation. Say which claims are backed by evidence (a video, logs, a working result) and which are not.

## Write up what I learned

> Using the template in community-knowledge/TEMPLATE.md, write a short note about what we tried in this session: the guide and version, the tools and platform, what worked, what didn't and the prompts that helped. Leave out names, emails, private file paths, API keys and other secrets. Show it to me; don't publish anything.
